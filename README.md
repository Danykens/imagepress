# Imagepress

Локальное приложение для пакетного сжатия изображений через FFmpeg. Русский интерфейс в браузере, выбор 100+ файлов, drag-and-drop, очередь из трёх параллельных обработчиков, скачивание по одному или ZIP-архивом. Файлы не отправляются в облако.

## Запуск

Нужен Python 3.10+ (на Windows при установке включите Python Launcher). FFmpeg автоматически устанавливается с `imageio-ffmpeg`; установленный системный FFmpeg имеет приоритет. Интернет нужен для первой установки зависимостей.

macOS / Linux:

```sh
sh start.sh
```

Windows: дважды нажмите `start.bat` или запустите его из терминала.

Откроется http://127.0.0.1:8765. Остановка — Ctrl+C в терминале. Другой порт: `sh start.sh --port 8766`. Без автоматического открытия браузера: `sh start.sh --no-browser`.

Если для вашей платформы нет готового FFmpeg в imageio-ffmpeg, установите системный FFmpeg или укажите путь через `FFMPEG_BINARY`.

## Использование

Быстрые пресеты: «Лёгкое» — качество 92%, исходные размеры; «Среднее» — 70%, сторона до 2560 px; «Сильное» — 45%, до 1920 px; «Баланс» — 80%, исходные размеры. Пресеты сохраняют выбранный JPEG/WebP; PNG переключают на WebP и отключают WebP без потерь. Поворот, отражение и фон остаются выбранными. Ручная настройка снимает выделение пресета. Итоговый вес зависит от изображения.

В блоке результатов есть две большие кнопки: «Скачать без ZIP» (каждое изображение отдельным файлом) и «Скачать ZIP». При нескольких загрузках браузер может запросить разрешение. Если загрузки заблокированы, используйте «Скачать файл» возле каждой картинки.

1. Выберите сразу все изображения в диалоге (Ctrl+A / Cmd+A) или перетащите их в окно.
2. Выберите WebP, JPEG или PNG, качество и при необходимости максимальную сторону.
3. Нажмите «Сжать изображения». Можно остановить очередь: до трёх уже начатых файлов завершатся. Повторный запуск обрабатывает **все загруженные оригиналы** с текущими настройками. Повторно выбирать файлы не нужно; результаты предыдущего запуска в списке заменяются.
4. Нажмите «Скачать» рядом с нужным файлом для скачивания без архива или скачайте общий ZIP. Нажатие миниатюры открывает оригинал в большом превью (HEIC/TIFF показываются в совместимой PNG-копии до 1280 px).

В «Расширенных настройках» доступны WebP без потерь, поворот на 90/180/270 градусов, горизонтальное/вертикальное отражение и цвет подложки для прозрачности при сохранении JPEG. Поворот выполняется перед отражением и уменьшением. При повороте, отражении, WebP без потерь или нестандартном фоне JPEG возврат меньшего оригинала отключён, чтобы выбранное преобразование применилось.

Вход: JPG, PNG, WebP, BMP, HEIC/HEIF, TIF/TIFF (регистр расширения не важен). До 50 МБ на файл и 2000 файлов в очереди. Для анимированных и многостраничных изображений обрабатывается только первый кадр/страница; для HEIC — основное изображение. GIF, SVG и RAW не поддерживаются в интерфейсе.

HEIC/HEIF сначала декодируется локально через Pillow и pillow-heif, затем сжимается FFmpeg. Эти зависимости устанавливаются автоматически через `start.sh` / `start.bat`. Результат — WebP, JPEG или PNG, не HEIC/TIFF. Если включено сохранение меньшего оригинала, результат может остаться в исходном формате. HDR HEIC приводится к 8 бит; сохранение HDR не предусмотрено. Некоторые браузеры не показывают миниатюры HEIC и TIFF — это не мешает обработке. Документация декодера: https://pillow-heif.readthedocs.io/en/stable/pillow-plugin.html.

WebP и JPEG сжимают с потерями; PNG — без потерь, если не менять размеры. JPEG получает белый фон вместо прозрачности. EXIF и другая метаинформация удаляются при перекодировании. Если включено «Не увеличивать вес», размеры не менялись, а результат больше оригинала, сохраняется исходный файл с исходным форматом и метаданными. Поэтому архив может содержать разные форматы. Для обязательной конвертации отключите эту опцию. Цветовые профили профессиональных материалов требуют отдельной проверки.

Результаты хранятся во временной папке до завершения сервера; очистка списка убирает только список в браузере. Скачивайте результаты до остановки приложения. После обновления страницы очередь не восстанавливается. Большие ZIP требуют свободного места на диске и памяти браузера.

## На других устройствах и GitHub

После публикации репозитория:

```sh
git clone <URL-репозитория>
cd imagepress
sh start.sh
```

На Windows используйте `start.bat`. Для обновления: остановите приложение, выполните `git pull`, запустите снова. Python и зависимости устанавливаются на каждом компьютере отдельно. Телефоны и планшеты не запускают этот локальный сервер штатным способом; текущая версия предназначена для macOS, Windows и Linux. GitHub хранит код, но не запускает FFmpeg: GitHub Pages для этого приложения не подходит.

Сервер слушает только 127.0.0.1, проверяет Host и защищает операции случайным токеном. Не публикуйте его напрямую в интернет. Оригиналы пользователя и временные результаты не попадают в репозиторий.

## Разработка и проверки

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m unittest discover -s tests -v
```

HTTP-сервер использует стандартную библиотеку Python; Pillow и pillow-heif нужны для HEIC. Frontend-сборка и Node.js не требуются. Параметры кодирования: https://ffmpeg.org/ffmpeg-codecs.html#libwebp.
