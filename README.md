# Imagepress

Локальное приложение для пакетного сжатия изображений через FFmpeg. Русский интерфейс в браузере, выбор 100+ файлов, drag-and-drop, очередь из трёх параллельных обработчиков, скачивание по одному или ZIP-архивом. Файлы не отправляются в облако.

## Запуск

Нужен Python 3.10+ (на Windows при установке включите Python Launcher). FFmpeg автоматически устанавливается с `imageio-ffmpeg`; установленный системный FFmpeg имеет приоритет. Интернет нужен для первой установки зависимостей.

macOS / Linux:

```sh
sh start.sh
```

Windows: дважды нажмите `start.bat` или запустите его из терминала.

Откроется http://127.0.0.1:8765. Остановка — Ctrl+C в терминале. Другой порт: `sh start.sh --port 8766`. Без автоматического открытия браузера: `sh start.sh --no-browser`.

Если для вашей платформы нет готового FFmpeg в imageio-ffmpeg, установите системный FFmpeg или укажите путь через `FFMPEG_BINARY`.

## Использование

1. Выберите сразу все изображения в диалоге (Ctrl+A / Cmd+A) или перетащите их в окно.
2. Выберите WebP, JPEG или PNG, качество и при необходимости максимальную сторону.
3. Нажмите «Сжать изображения». Можно остановить очередь: до трёх уже начатых файлов завершатся. Повторное нажатие продолжит очередь и повторит файлы с ошибками.
4. Скачайте файлы или общий ZIP. Для повторной обработки готовых файлов очистите список и добавьте их заново.

Вход: JPG, PNG, WebP, BMP, TIFF. До 50 МБ на файл и 2000 файлов в очереди. Для анимированных и многостраничных изображений обрабатывается только первый кадр/страница; GIF, SVG, RAW и HEIC не поддерживаются в интерфейсе.

WebP и JPEG сжимают с потерями; PNG — без потерь, если не менять размеры. JPEG получает белый фон вместо прозрачности. EXIF и другая метаинформация удаляются при перекодировании. Если включено «Не увеличивать вес», размеры не менялись, а результат больше оригинала, сохраняется исходный файл с исходным форматом и метаданными. Поэтому архив может содержать разные форматы. Для обязательной конвертации отключите эту опцию. Цветовые профили профессиональных материалов требуют отдельной проверки.

Результаты хранятся во временной папке до завершения сервера; очистка списка убирает только список в браузере. Скачивайте результаты до остановки приложения. После обновления страницы очередь не восстанавливается. Большие ZIP требуют свободного места на диске и памяти браузера.

## На других устройствах и GitHub

После публикации репозитория:

```sh
git clone <URL-репозитория>
cd imagepress
sh start.sh
```

На Windows используйте `start.bat`. Для обновления: остановите приложение, выполните `git pull`, запустите снова. Python и зависимости устанавливаются на каждом компьютере отдельно. Телефоны и планшеты не запускают этот локальный сервер штатным способом; текущая версия предназначена для macOS, Windows и Linux. GitHub хранит код, но не запускает FFmpeg: GitHub Pages для этого приложения не подходит.

Сервер слушает только 127.0.0.1, проверяет Host и защищает операции случайным токеном. Не публикуйте его напрямую в интернет. Оригиналы пользователя и временные результаты не попадают в репозиторий.

## Разработка и проверки

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m unittest discover -s tests -v
```

Приложение использует стандартную библиотеку Python, без frontend-сборки и Node.js. Параметры кодирования: https://ffmpeg.org/ffmpeg-codecs.html#libwebp.
